# TenderGuard

## Project Title

TenderGuard — AI-Powered Tender Compliance Validator

---

## The Problem

Evaluating vendor proposals against a Request for Proposal (RFP) is a manual and time-consuming task. Teams must extract requirements, verify compliance, and identify risks across lengthy documents, which increases the likelihood of oversight and inconsistent evaluation.

---

## The Solution

TenderGuard is an AI-based system designed to automate tender evaluation. It extracts requirements from RFP documents, validates vendor proposals using semantic matching, detects potential risks, and presents results through a structured comparison dashboard.

The system provides a clear and explainable workflow, enabling faster and more reliable decision-making.

---

## Tech Stack

* **Programming Languages:** Python, JavaScript
* **Frameworks:** Flask
* **Frontend:** HTML, CSS
* **Data Handling:** JSON, CSV
* **AI / NLP:** Semantic similarity models, keyword-based heuristics

## Project Overview

The system follows a structured workflow:

1. Upload an RFP document
2. Extract mandatory requirements
3. Review and confirm the checklist
4. Upload vendor proposals
5. Validate proposals against requirements
6. Identify risks and missing elements
7. Compare vendors using a dashboard

---

## Key Features

* Automated requirement extraction from RFP documents
* Semantic matching between requirements and vendor proposals
* Identification of missing or partially addressed requirements
* Detection of risky or vague clauses in vendor submissions
* Compliance scoring and vendor comparison dashboard
